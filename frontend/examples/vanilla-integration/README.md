# Vanilla HTML/JS Integration Example

Standalone HTML page that loads `<odrl-policy-editor>` from a CDN.

## Setup

1. Start the ODRL PAP backend (default: `http://localhost:8080`)
2. Open `index.html` in a browser (or serve with `npx serve .`)
3. Adjust the **API Base URL** in the config panel to match your backend
4. Use the dropdowns to change theme, locale, and mode at runtime
5. Check the **Event Log** panel at the bottom for component events
