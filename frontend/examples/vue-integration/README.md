# Vue 3 Integration Example

Minimal Vue 3 wrapper component for `<odrl-policy-editor>`.

## Setup

1. `npm install @seamware/odrl-policy-editor`
2. Add `isCustomElement` to your `vite.config.ts` (see [integration guide](../../docs/integration-generic.md#vue-3))
3. Copy `OdrlPolicyEditor.vue` into your `src/components/` directory
4. Import and use the component in your Vue templates
5. Set `api-base-url` to your ODRL PAP backend URL
